NO-CODECaptivateIQ — Plan Builder & Formula Editor

Forrester Wave Leader (Q1 2025). No-code, spreadsheet-like SmartGrid. ~800+ customers, $2B+ commissions processed. What follows is the real admin UI per CaptivateIQ's own product vignettes and public tour.

1. Plan creation — the blueprint wizard

Admins configure a plan through a step wizard. Step chaining in the public tour: General settings → Credits → Additional columns → Input parameters → Summary.

Real UI — "Configure your flat rate Flat Rate: Services blueprint": Payout frequency (fixed frequency Monthly + Fiscal year start month, or custom frequency from a table column), Commission rate (same rate for all payees, or unique per payee), Quota and attainment section below. Cancel / Previous / Next footer.

Credit mapping

Plan credits mapping wizard — choose the Credit ID, credit date and payee fields from source data. This is how deal/booking rows become commissionable credits for the plan.

Tiered vs flat blueprint configuration

Tiered rate config: tier bands with conditions like Tier 1 [Cumulative commissionable total] < [Tier 2 target] and rates as % or multiplier, per tier.
Flat-rate blueprint: payout frequency + fiscal year start (or custom frequency column), same-rate vs per-payee rate.

2. The calculation workbook (where plans live)

The plan workbook: tabs Overview, Payout dates, Employee assumptions, Calculation workbook, Statement designer, What-if tool. Bulk edit columns; "Powered by SmartGrid". The "Calculation workbook" holds the plan-element graph. The plan element graph: data sources (e.g. Final Bookings Data, Rates, YTD Deals) with Add a plan element — plan elements are the building blocks (credits → blueprint → payout).

Choosing and configuring a plan element

"Choose a plan element": Plan credits, or a blueprint — Flat rate / Tiered / Conditional — plus Component instance (e.g. "Services").
"Configure your tiered blueprint": Quota and Base Rate inputs, an fx button on rate inputs, Tier bands with rates.

3. The formula editor — column Formulas dialog

Formulas live on columns in SmartGrid tables. A derived column opens the Formulas dialog; the formula references other columns with {Column Name}.

Real UI — the Formulas dialog: Variant, Column Name, Description, Data Type, Format, Decimal Places, and the Formula box: {Base Commissions Earned} + {Paid Upfront Bonus} + {Multi-Year Bonus}. Note the Explain Formula button (AI explainer) in the same dialog.

Worksheets and source data

Worksheet view: tabs for Bookings Data / Payments / Overrides; columns are edited with formulas, and results recalculate in real time (SmartGrid's dependency graph).
How formulas get inserted into plans: you don't paste formulas into a plan — you build derived columns in SmartGrid worksheets/tables. Plan credits map rows to payees, blueprints (flat/tiered/conditional) or component instances compute payout, and they all read those columns. Named Global Attributes and reusable Calculation Components share formulas across plans; the Comp Builder Agent can draft formulas and columns from a text description.
