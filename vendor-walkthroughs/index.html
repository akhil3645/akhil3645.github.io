Enterprise ICM — Plan Builder & Formula Editor Walkthroughs

Six large, mature incentive compensation platforms. For each: how the plan builder looks and works, and exactly how admin-written formulas/expressions get inserted into plans. Screenshots are real UI from vendor docs, product tours, Trailhead, SAP Learning, Oracle readiness docs, and official videos.

NO-CODE + AI 1. Varicent

Incentives Designer canvas with AI assistant building tool chains (Filter, Case, Change Type), tests + data preview + explain panel; ELT pipes with low-code Formula tool and full function library.

Source of truth: Varicent product tour MP4s (CDN) + ELT docs + local frames.

NO-CODE 2. CaptivateIQ

Guided Plan Builder wizard (settings → credits → columns → params → summary), tiered/flat blueprints, credit mapping, and the per-column Formulas dialog with {Column} references and "Explain Formula".

Sources: CaptivateIQ site vignettes + public Navattic tour stills + blog.

LOW-CODE 3. Xactly Incent

Plan Design module: Rules Library, 3-step rule wizard (name/type → conditions → results), Formulas and Rate Tables tabs; rules generate credits/results that plans consume.

Sources: Xactly official "Building a SPIF" demo frames, admin/rep tour stills, product video.

SALESFORCE-NATIVE 4. Salesforce Spiff

Designer: datasheets (line-by-line), worksheets (lump-sum), payout rules pointing at Payout Amount fields, formula bar with function library (tier_payout), and the click-through trace view.

Sources: Trailhead screenshots (vendor CDN), formula trace stills.

FUNCTIONS 5. SAP Commissions

Plan Data / Rules Wizard with rule types (Credit, Measurement, Incentive, Commission, Deposit), condition/output expression editors, reusable Functions vs Formulas with Rule Usage, and the Compensate & Pay pipeline.

Sources: SAP Learning screenshots, SAP Community blogs, SAP Help guides.

SQL-LIKE 6. Oracle Incentive Compensation

Plan components wired to measures and incentive formulas; SQL-like reusable Expressions inserted as measure formulas (attainment) or incentive formulas (earnings) or rate-table inputs; predefined PL/SQL functions + AI expression builder.

Sources: Oracle readiness/using docs screenshots, legacy UI captures, Oracle docs text.

How to read these

No-code layers

Canvases, wizards, grids, dropdown conditions. What a comp admin uses for 80% of changes.

Formula/expression layer

Where the actual math lives — a per-column dialog, a rule result, a function call, or a SQL-like expression — and how the plan references it.
