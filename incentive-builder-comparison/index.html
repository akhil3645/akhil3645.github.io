What this demo does—and doesn’t do

        

          A small parser compiles the supported formulas into V2-shaped
          expressions without executing JavaScript from the editor. The browser
          evaluates fictional inputs. These previews are
          not verified by the backend; this is not the complete
          V2 validator or numeric runtime.
        

        

          SUM_WHERE(value, condition) is demo authoring shorthand
          for an aggregate with a filter, not a new V2 operation.
          Conditions support one ALL/ANY group here. Formula mode supports
          nested expressions. Invalid edits never replace the output with stale
          JSON.
        

        

          Supported formula syntax
          

            References shown in each picker; numbers, quoted text and
            TRUE/FALSE; + − * /; =, !=, <, >, <=, >=; AND/OR;
            parentheses; CASE(condition, result, …, fallback), COALESCE,
            GREATEST, LEAST; SUM, AVERAGE, COUNT(field), SUM_WHERE,
            AVERAGE_WHERE, COUNT_WHERE. The *_WHERE helpers compile to an
            aggregate with a filter. CASE uses first-match order. Division by
            zero returns null.
